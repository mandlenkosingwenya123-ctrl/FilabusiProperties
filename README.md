# FilabusiProperties

## Overview
FilabusiProperties is a web project designed to display property listings, showcase architectural designs, and manage real estate visualizations for Filabusi.

## Features
- **Property Listings:** Browse available residential and commercial properties.
- **Architectural Sketches:** View detailed 2D/3D property renderings and floor plans.
- **Contact & Inquiries:** Directly contact the agent for property details and viewings.

## Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript
- **Hosting:** GitHub Pages
